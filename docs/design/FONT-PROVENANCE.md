# Local SF fonts

User-requested static SF Pro Text and SF Pro Display, SF Pro Rounded, and SF Mono were downloaded from Apple’s official font page, https://developer.apple.com/fonts/, to this machine’s font directory. The variable SF Pro face was removed from the active font directory after incorrect width/spacing was reported. Static named faces now supply the interface, display, rounded clock, and monospace roles.

Apple’s proprietary font license applies. Font binaries are not part of this source port or its distributable assets. Existing Open Runde assets remain as upstream fallbacks.
